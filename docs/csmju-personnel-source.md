# ข้อมูลบุคลากรจากเว็บสาขา

แหล่งข้อมูล: https://www.csmju.com/personnels

ในหน้าจัดการ ส่วน “บุคลากรและห้องทำงาน” กด “ดึงข้อมูลจากเว็บสาขา” เพื่อเพิ่มหรืออัปเดตชื่อไทย–อังกฤษ ประเภท ตำแหน่ง รูป อีเมล โทรศัพท์ และการศึกษา จากรายการบุคลากรที่ทำงานปกติบนเว็บสาขา ระบบแสดงภาพจาก URL ต้นทางโดยตรงและมีลิงก์ประวัติ

ระบบจับคู่ด้วยรหัสต้นทางก่อน จากนั้นใช้ชื่อเต็มที่ตัดคำนำหน้าหรืออีเมลตรงกันกับรายการเดิม หากพบชื่อซ้ำที่จับคู่ไม่ชัดเจน ระบบข้ามและแจ้งผู้ดูแลตรวจสอบ การดึงซ้ำรักษารหัสบุคลากรที่ใช้ในแผนที่ ห้องทำงาน และคาบสอนเดิม แต่จะอัปเดตข้อมูลประวัติด้วยค่าจากต้นทางอีกครั้ง รายการที่ไม่พบในต้นทางจะไม่ถูกลบ

การดึงเป็นคำสั่งของผู้ดูแล ไม่ใช่การซิงก์เบื้องหลัง หน้าเว็บสาขาปัจจุบันเผยแพร่ข้อมูล JSON ของรายการผ่าน HTML ตัวเชื่อมต่ออ่านเฉพาะ query บุคลากรและตรวจว่ามาครบหนึ่งหน้า หากโครงสร้างต้นทางเปลี่ยนหรือดึงไม่สำเร็จ จะไม่แก้ข้อมูลที่เก็บไว้ ไม่มีการเชื่อม Core Hub เพื่ออ่านบุคลากร

API: `POST /api/v1/lecturers/import-csmju` ต้องมีทั้งสิทธิ์เพิ่มและแก้บุคลากร ตอบจำนวนเพิ่ม/อัปเดตและชื่อที่ต้องตรวจสอบ

ก่อนเปิดบริการรุ่นใหม่ให้รัน `prisma migrate deploy` และ `prisma generate` สำหรับ migration `20261008160000_csmju_personnel_source`
