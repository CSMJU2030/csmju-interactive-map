# การเข้าชมเว็บจริง

หน้า `/map`, `/locations`, `/personnel` และ `/about` เปิดให้ทุกคนดูได้โดยไม่ต้องเข้าสู่ระบบ เมนูคณาจารย์และเจ้าหน้าที่แสดงสำหรับผู้เข้าชมทั่วไปด้วย บัญชีที่หมดอายุไม่บังคับเปลี่ยนหน้าเมื่อกำลังดูหน้าสาธารณะ

เปิดเฉพาะ API อ่านสถานที่ที่เปิดใช้งาน ค้นหา รายละเอียดสถานที่ ผังทางเดิน และ directory บุคลากร การเพิ่ม แก้ไข ลบ ดึงข้อมูลจากเว็บสาขา ดึงตารางทะเบียน รายการหลังบ้าน และข้อมูลผู้ใช้ ยังต้องใช้ Core Hub authentication และสิทธิ์เดิม

ข้อมูลบุคลากรที่ดึงมาใน Local เป็นข้อมูลในฐานทดสอบ ไม่ได้ถูกย้ายไปฐานเว็บจริงโดยอัตโนมัติ เมื่อนำ backend/frontend รุ่นนี้ขึ้นเว็บจริง ให้รัน migrations/generate แล้วให้ผู้ดูแลกด “ดึงข้อมูลจากเว็บสาขา” บนเว็บจริง เพื่อเติมข้อมูลในฐานจริง จากนั้นกำหนดห้องทำงานและคาบสอนตามที่ต้องการ

ทดสอบผ่าน AppModule และ guards จริงโดยไม่มี cookie/token: API อ่านสาธารณะตอบ 200; API จัดการและ import ตอบ 401
