# ห้อง บุคลากร และตารางสอน

การเปลี่ยนแปลงนี้ใช้ข้อมูลห้องและบุคลากรที่ผู้ดูแลบันทึกในระบบแผนที่ ตามคำขอวันที่ 8 ตุลาคม 2569 แทนการดึงข้อมูลเก่าจาก Core Hub การเข้าสู่ระบบและสิทธิ์ยังใช้ Core Hub SSO

## วิธีใช้งาน

1. ในหน้า **จัดการแผนที่** เพิ่มหรือแก้ไขชื่อสถานที่และรหัสห้องได้โดยตรง
2. ใน **บุคลากรและห้องทำงาน** กรอกรหัส ชื่อ ประเภท ตำแหน่ง และอีเมล แล้วกำหนดสถานที่ที่เปิดใช้งานเป็นห้องทำงานได้
3. ใต้รายการสถานที่ ใช้ **จัดการตารางสอนประจำห้อง** เลือกห้อง แล้วเพิ่มอาจารย์ วิชา วัน เวลา และช่วงวันที่ของภาคเรียน กด **บันทึกตารางสอน**
4. หรือเลือกปีการศึกษา/ภาคเรียน แล้วกด **ดึงตารางสอนวิทย์คอมจากทะเบียน** เลือกชื่อห้องจากทะเบียนเพื่อจับคู่กับห้องบนแผนที่ กำหนดวันที่เริ่มและสิ้นสุด ตรวจตัวอย่างก่อนกดนำเข้าและบันทึกตารางสอน

การนำเข้าสร้างบุคลากรที่ยังไม่มีในระบบทันที แต่ตารางสอนจะบันทึกเมื่อกดบันทึกตารางสอน รหัสบุคลากรที่นำเข้าเป็นรหัสเฉพาะในระบบนี้และแก้ไขได้ การจับคู่ชื่อจะละตำแหน่งทางวิชาการและช่องว่างออกก่อนเปรียบเทียบ การแก้ชื่อและตำแหน่งสถานที่จะไม่เปลี่ยนตารางสอน

ห้องทำงานและห้องสอนเป็นข้อมูลคนละส่วน รายละเอียดบนแผนที่และหน้าบุคลากรแสดงการสอนขณะนี้ตามเวลา Asia/Bangkok โดยตรวจทุก 15 วินาที การคำนวณรวมเวลาเริ่มและไม่รวมเวลาสิ้นสุด และไม่แสดงคาบที่อยู่นอกช่วงวันที่ใช้งาน ข้อความนี้อ้างอิงตารางที่บันทึก ไม่ใช่การยืนยันการอยู่ในห้องจริง

## แหล่งทะเบียน

ใช้หน้า public HTML ของ [ระบบทะเบียนแม่โจ้](https://reg.mju.ac.th/registrar/class_info.asp) ฝั่ง backend ถอดรหัสภาษาไทย Windows-874 และค้นรายวิชา `10301*` ของวิทยาการคอมพิวเตอร์ วิทยาเขตเชียงใหม่ ไม่ใช้ตารางของทั้งคณะหรือข้อมูล Core Hub

ตัวเชื่อมต่อนี้ครอบคลุมรายวิชารหัส 10301 ที่เปิดสอน ไม่รวมรายวิชาศึกษาทั่วไป รายวิชาสาขาอื่น หรือรหัส คพ เก่า หากต้องการข้อมูลเหล่านี้สามารถเพิ่มเองได้ รายชื่อผู้สอนในรายวิชาอาจมีผู้ร่วมสอนจากสาขาอื่นตามที่ทะเบียนประกาศ

เลือกปีและภาคเรียนทุกครั้งที่ดึงข้อมูล และกำหนดวันเริ่ม–สิ้นสุดจริงเอง ชื่อห้องทะเบียนไม่จำเป็นต้องตรงกับรหัสห้องแผนที่ จึงใช้การจับคู่ที่ผู้ดูแลเลือก ตัวเชื่อมต่อเป็นการดึงตามคำสั่ง ไม่ซิงก์อัตโนมัติ และยังไม่มี API JSON ทางการที่ตรวจยืนยันได้ หากหน้า HTML เปลี่ยนหรือทะเบียนไม่ตอบ ให้ใช้ฟอร์มแก้ไขเอง

ระบบตรวจวันจริง เวลาเริ่มก่อนสิ้นสุด และคาบซ้อนในห้องเดียวกัน/อาจารย์เดียวกันข้ามห้อง อนุญาตผู้ร่วมสอนคนละคนในวิชาและช่วงเวลาเดียวกัน

## ฐานข้อมูลและการนำขึ้นระบบ

ก่อนเปิด backend รุ่นนี้บนเซิร์ฟเวอร์ ให้รัน:

```powershell
pnpm --filter @csmju-interactive-map/backend exec prisma migrate deploy
pnpm --filter @csmju-interactive-map/backend prisma:generate
pnpm build
```

Migration `20261008090000_local_rooms_personnel_schedule` รักษาตำแหน่งแผนที่และการกำหนดห้องเดิมไว้ เพิ่มคอลัมน์ข้อมูลบุคลากรและตารางคาบสอน ชื่อที่ migration รุ่นก่อนลบไปแล้วจะใช้รหัสห้อง/รหัสบุคลากรเป็นค่าเริ่มต้นให้ผู้ดูแลตรวจและแก้เอง โดยไม่คัดลอกข้อมูลเก่าจาก Core Hub

การลบห้องหรือบุคลากรจะลบคาบสอนที่อ้างอิงรายการนั้นด้วย ไม่ได้เผยแพร่การเปลี่ยนแปลงขึ้นเซิร์ฟเวอร์จริงจากการทดสอบใน workspace นี้

## เปิดเว็บระหว่างพัฒนา

ใช้ Node.js 22 และ PostgreSQL ตาม `backend/.env` ตั้ง `BACKEND_INTERNAL_URL=http://127.0.0.1:4202` ใน `frontend/.env.local`:

```powershell
pnpm dev
```

เปิด `http://localhost:3216/admin` และเข้าสู่ระบบผ่าน Core Hub ด้วยบัญชีที่มีสิทธิ์จัดการ ไม่มีทางเข้าผู้ดูแลทดสอบอัตโนมัติ
