02 / 06

ทำไมถึงต้องมี CSMJU Interactive Map?

เปลี่ยนปัญหาแผนผังกระดาษเดิมๆ ให้เป็นระบบนำทางและสืบค้นอัจฉริยะของสาขา

⚠️

ปัญหาเดิมของสาขา (Pain Points)

  • ผังอาคารเป็นรูปภาพนิ่ง (Static Image): ไม่สามารถค้นหาชื่อห้อง รหัส หรืออาจารย์ได้
  • นักศึกษาใหม่และบุคคลภายนอกหลงทาง: ไม่ทราบว่าห้องปฏิบัติการหรือห้องพักอาจารย์อยู่ที่ชั้นไหน
  • ข้อมูลไม่เป็นปัจจุบัน: เมื่อมีการย้ายห้องพักหรือเปลี่ยนอาจารย์ประจำห้อง ข้อมูลในป้ายประกาศไม่อัปเดต
  • ขาดการเชื่อมต่อกับระบบกลาง: ระบบเดิมทำงานแยกเดี่ยว ข้อมูลไม่ลิงก์กับ Ecosystem ของสาขา
💡

เป้าหมายและสิ่งที่ระบบตอบโจทย์ (Solutions)

  • Interactive SVG Floor Plan: แผนผังแบบ Vector ตอบสนองการคลิก Hover และไฮไลท์ตำแหน่งชัดเจน
  • ค้นหาแม่นยำ (Instant Search): เสิร์ชหาจากชื่อห้อง, รหัสห้อง, หมวดหมู่ หรือแม้แต่ชื่ออาจารย์ได้ทันที
  • Room Details & QR Code: แสดงรูปภาพ รายการอุปกรณ์ในห้อง พร้อม QR Code ให้สแกนเปิดบนมือถือ
  • Plug-in Architecture: เสียบเข้ากับ CSMJU2030 ได้ทันทีโดยไม่ต้องสร้างระบบ Login ซ้ำซ้อน
ความต้องการ: อำนวยความสะดวกในการค้นหาสถานที่แก่นักศึกษาและอาจารย์

03 / 06

สถาปัตยกรรมระบบ Tech Stack & Integration

โครงสร้างแบบ Decoupled แยก Frontend, Backend และต่อเชื่อมระบบกลางผ่าน API Gateway

💻

Frontend Stack

  • Next.js (App Router): Server & Client Components ความเร็วสูง
  • TypeScript & Tailwind CSS: Strict Type ปลอดภัย ดีไซน์ทันสมัย
  • Interactive SVG Engine: ควบคุมสถานะห้อง, พิกัด, สี และ Layer
  • QR Code Generator: สร้าง Dynamic URL ให้ผู้ใช้เปิดบนมือถือ
⚙️

Backend Stack

  • NestJS Framework: สถาปัตยกรรม Modular ดูแลง่ายในระยะยาว
  • PostgreSQL & Prisma ORM: ฐานข้อมูลเสถียรสูง พร้อม Type-safe Schema
  • RESTful API v1: OpenAPI / Swagger Document อัตโนมัติ
  • Class Validator & DTO: ตรวจสอบความถูกต้องของ Input ทุกระดับ
🛡️

Security & RBAC

  • Gateway-Header Auth: รับข้อมูลตัวตนจาก CSMJU Gateway ปลอดภัย
  • Zero Password Storage: ไร้ความเสี่ยง ไม่เก็บรหัสผ่านซ้ำซ้อน
  • Two-Tier RBAC:
    • Guest: ดู/ค้นหาแผนที่ (Student, Alumni)
    • Editor: เพิ่ม/แก้ไขข้อมูล (Staff, อาจารย์)
    • Admin: จัดการสิทธิ์ ลบข้อมูล และควบคุมระบบ
